# /plan [topic] — Activity Planning

Design a classroom activity differentiated for the full range of students.

## Steps

1. Read `memory/class-roster.md` — understand communication levels and any active alerts
2. Read `memory/teacher-profile.md` — classroom equipment available, teaching approach
3. If [topic] is not provided, ask: "What topic or skill area do you want to focus on today?"

## Design activities for 3 levels

Always differentiate across these three levels based on the class roster:

| Level | Who | Design principle |
|-------|-----|-----------------|
| **Level A** | Non-verbal (PECS/AAC) | Visual-only instructions, concrete objects, no verbal requirement, clear start/finish |
| **Level B** | Minimally verbal | Short sentence instructions, visual supports, some verbal response expected |
| **Level C** | Verbal / higher support | Can follow multi-step verbal instructions, may read basic words |

## Malaysian context
- Reference materials available in Malaysian schools (not expensive imported resources)
- Activities should be culturally appropriate (Malaysian context, BM and English labels)
- Suggest local equivalents where relevant

## Notes for Claude
- Never design an activity that requires non-verbal students to respond verbally
- Always include a "sensory notes" section — check student profiles for known sensory issues
- If an activity has specific risks for a student (e.g., elopement during outdoor activity), flag it explicitly
- Keep materials simple — assume limited resources unless teacher-profile specifies otherwise

# /message [name] — Draft Parent/Guardian Message

Draft a message to a student's parent or guardian.

## Steps

1. Read the student's profile (`students/S*-[name].md`) — Section 8 (Parent/Guardian)
2. Note: preferred language (BM or English), preferred contact method, standing notes

## Ask the teacher

1. **What's the message about?**
   - Positive update / milestone
   - Incident / concern
   - IEP update
   - Appointment reminder
   - General check-in
   - Other

2. **What happened / what do you want to communicate?** (teacher's own words — no need for perfect sentences)

3. **Tone?**
   - Warm and informative (default)
   - Sensitive / difficult topic
   - Celebratory

4. **Language?** (check parent profile — suggest their preference, but let teacher confirm)

## Draft the message

Write a complete, ready-to-send message. Format:

**For WhatsApp (most common in Malaysia):**
Short, warm, clear. Not too formal. Conversational but professional.

```
Assalamualaikum / Selamat pagi [Parent name],

[Main message — clear, honest, warm]

[If incident: what happened, what was done, how student is now]
[If positive: specific milestone or behaviour to celebrate]

Terima kasih / Thank you,
[Teacher name]
Cikgu Kelas Pendidikan Khas
```

**For BM messages:**
Use proper Bahasa Malaysia. Not rojak unless the teacher uses it with this parent.

**For formal written note (sent home):**
More formal structure. Header with school name and date.

## Rules for difficult messages (incidents, concerns)

- **Lead with student's wellbeing** — "Izzat is safe and calm" before describing what happened
- **Facts only** — describe behaviour and events, not interpretations or blame
- **What was done** — always include what the teacher did to help
- **Next steps** — give the parent something concrete (e.g., "Please let me know if he mentions anything at home about [X]")
- **Never alarming without context** — if it was a meltdown, normalise: "This can happen during transitions — we handled it together"

## After drafting

Ask: "Would you like to log this communication in `logs/parent-comms.md`?"
If yes: append a summary entry automatically.

## Notes for Claude
- Match the language to the parent's documented preference — do not default to English if BM is preferred
- Keep WhatsApp messages under 5 short paragraphs — parents read on phone
- Never share specific details about other students in a message about one student
- If the topic is about suspected abuse, neglect, or child protection — DO NOT help draft this as a casual message. Say: "This sounds like it may need to be reported through official school channels first. Please speak with your school counsellor or Guru Besar before contacting the parent directly."

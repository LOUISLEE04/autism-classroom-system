# /emergency [name] — Emergency Protocol

## ⚠️ This command is for urgent situations. Speed matters.

## What to do

1. Read the student's profile immediately (`students/S*-[name].md`)
2. Display ONLY the critical information — no analysis, no research, no preamble

## Output format (this exact structure, nothing else)

```
🚨 EMERGENCY — [NAME]

COMMUNICATION: [e.g., Non-verbal — PECS Phase 3. During crisis: offer choice of 2 objects only. Do NOT require communication.]

DE-ESCALATION STEPS:
1. [Step 1 from profile]
2. [Step 2 from profile]
3. [Step 3 from profile]

❌ DO NOT:
- [Thing that makes it worse #1]
- [Thing that makes it worse #2]

ELOPEMENT: [Yes — [specific protocol] / No]
SELF-INJURY: [Yes — [redirect to X] / No]

📞 CALL NOW IF NEEDED:
[Parent name]: [Phone]
Admin: [From teacher profile]
Emergency (999): Seizure / serious injury

AFTER: Log in /log when student is settled.
```

## Rules for Claude
- Show ONLY what is documented — do not add generic advice unless the profile is missing critical sections
- If a section is blank in the profile, say "[Not documented — update student profile]" — do not fill in with assumptions
- No long paragraphs — bullet points only
- If the student's name is ambiguous or not found, ask to clarify rather than guessing
